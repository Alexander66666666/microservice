# 🛒 Order Service - Spring Boot REST API

![Java](https://img.shields.io/badge/Java-17-blue)
![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.x-green)
![Spring Security](https://img.shields.io/badge/Spring%20Security-6.x-red)
![JWT](https://img.shields.io/badge/JWT-Auth-orange)

Полнофункциональное REST API для управления заказами с аутентификацией JWT.

## 🚀 Особенности
- ✅ JWT аутентификация и авторизация
- ✅ Управление пользователями и ролями
- ✅ CRUD операции для заказов
- ✅ Пагинация и фильтрация
- ✅ Полная JavaDoc документация
- ✅ Swagger/OpenAPI документация
- ✅ Глобальная обработка исключений

## 🛠️ Технологии
- **Backend:** Java 17, Spring Boot 3
- **Security:** Spring Security, JWT
- **Database:** Hibernate, H2 (для разработки)
- **Documentation:** Swagger, JavaDoc
- **Build:** Maven
